Proyecto Examen final

Sistema Web de Control de Rutas y Transporte de Carga
Se abre desde el archivo auth.html

Para iniciar sesion usar:
COMO ADMINISTRADOR
'admin@logitrans.com', (CORREO)
    'admin', (USUARIO)
    'admin123', (CONTRASEÑA)
  COMO LOGISTICO
  logistica@logitrans.com', (CORREO)
    'logistica', (USUARIO)
    'logistica123 (CONTRASEÑA)

Las funciones de las paginas son las siguientes
Auth.html -> Donde se realiza el inicio de sesion
Index.html -> Pagina principal con las opciones.
Conductores.html -> se crea,edita, consulta y cambia su estado.
Vehículos.html ->se crea,edita, consulta y cambia su estado
Rutas.html -> se crea,edita y consulta.
Programaciones.html -> Se programa el viaje,consulta programación y se reprograma
Viajes.html -> Se inicia el viaje, registra novedades, se finaliza y se cambian los estados
